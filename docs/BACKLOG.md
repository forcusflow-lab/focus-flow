# Focus Flow Backlog

このドキュメントは、コード調査およびテスト検証から客観的に確認された既知の課題・今後の改善タスクを管理するバックログです。

---

## 優先度定義

- **P0**: アプリが正常に動作しない、クラッシュする等の重大な問題（即時対応）
- **P1**: ユーザー体験（UX）や主要機能の挙動・操作性に直接影響する重要な問題
- **P2**: デザインシステムの統一、視覚的一貫性、細部のUI/UX調整
- **P3**: 将来的な拡張、CI/CD整備、コードベースの保守性向上
