# Focus Flow 全画面・全状態監査記録

## 監査基準

本監査は、画面単位の表示品質だけでなく、保存後の状態、Widget同期、Androidの遮断導線、戻る操作、空・読み込み・エラー状態を対象とする。評価は**正常、要修正、実機受入が必要**の三段階で記録する。

| 対象 | 監査観点 | 初期判定 | 対応方針 |
|---|---|---|---|
| Todo・サブタスク | 親Todo完了、サブタスク表示、編集、削除 | 要修正 | Widget操作でサブタスクを失わないこと、カードと詳細導線を分離することを検証する。 |
| 習慣 | チェック、回数、時間、詳細展開 | 要修正 | 画面本体・Today・Widgetで同じ進捗計算を使うことを検証する。 |
| Today | 必須抽出、完了一覧、詳細遷移 | 要修正 | Todoと習慣のカード操作を統一し、完了操作で詳細を開かないことを確認する。 |
| 設定 | 制限、時間帯、表示、Widget、通知、Plus | 要修正 | テーマ・文字・Widget設定の反映先と、Android戻るを確認する。 |
| メモ | 編集、Todo移植、削除 | 要修正 | テーマ色の直書き排除と、本文移植・削除確認を検証する。 |
| 振り返り | 週次集計、解除条件の説明 | 要修正 | テーマ色と長い数値・翻訳文の可読性を確認する。 |
| 法務・サポート | Stack遷移、戻る、クラッシュ | 実機受入が必要 | 全ルートがProvider内で表示されることを自動検証する。 |
| Widget | 追加、更新、完了・復元、テーマ、透明度、サイズ | 要修正 | 静的RemoteViews経路、資産コピー、ID整合、重複除去を検証する。 |
| 集中制限 | 前面アプリ遮断、Todayへの遷移、厳格モード | 実機受入が必要 | 連続イベントでも遮断UIがちらつかず、CTAがTodayを一度だけ開くことを検証する。 |
| 起動・テーマ | 起動面、明暗・テーマ、文字倍率 | 要修正 | 画面ごとのハードコード色と縮小・省略指定を確認する。 |

## 初期確認で検出した主なリスク

| ID | 重要度 | 内容 | 根拠・影響 |
|---|---|---|---|
| FF-001 | Critical | WidgetからTodoを完了・復元するとサブタスク配列を空にする経路がある。 | Widgetアクションの同期後に、親Todoの分解情報が失われる。 |
| FF-002 | High | メモ・振り返りに固定色のテキストスタイルが残る。 | ダークテーマやテーマ変更時に視認性が落ちる。 |
| FF-003 | High | Widgetは静的RemoteViewsに統一済みだが、表示経路の資産・ID・幅の整合が崩れると配置不能になる。 | Android生成後のリソース検証と契約テストが必要。 |
| FF-004 | Medium | Todo・習慣・Todayのカードは同じ概念を別の高さ・メタ情報で表示する箇所がある。 | 表示内容とイベント分離を共有コンポーネントで固定する。 |
| FF-005 | Medium | 多くの画面に`numberOfLines`が残り、重要な説明や設定名が文字倍率で省略されるおそれがある。 | 見出し・設定名・必須・期限は省略せず、要約文だけに省略を限定する。 |

## 受入判定の原則

1. データを失う経路、Widget配置不能、制限対象の誤遮断・未遮断、クラッシュは**Critical**として残さない。
2. 画面テーマで読めない文字、明確なタップ競合、戻れない画面、誤解を招く文言は**High**として修正後に再検証する。
3. 実機固有のランチャー、アクセシビリティ許可、Google Play署名は自動生成とコード検証後に実機受入へ回す。

## 修正・再検証結果

| ID | 結果 | 実施内容 | 検証状態 |
|---|---|---|---|
| FF-001 | 修正済み | Widgetアクション同期後も既存Todoの`subtasks`を保持するようにした。 | ユニット・回帰テストで確認済み。 |
| FF-002 | 修正済み | メモ、振り返り、その他画面の主・副テキストを動的paletteで描画するようにした。 | 全テーマの静的契約と型検査で確認済み。 |
| FF-003 | 修正済み（実機受入待ち） | Widgetの静的RemoteViewsを安全な固定幅構成へ保ち、サイズ別に行数を実高さから決めるようにした。 | Android prebuild、資産・Manifest・Widget契約テストは通過。ランチャー配置は実機受入が必要。 |
| FF-004 | 修正済み | Todo・習慣カードのチェック、詳細、展開を別タップ領域に固定し、習慣削除を詳細フォームへ移した。 | カード・詳細遷移・削除導線の回帰テストで確認済み。 |
| FF-005 | 修正済み | 必須・期限・サブタスク名などの重要表示は省略しない実装へ寄せ、操作領域との競合を回避した。 | UI契約テストで確認済み。 |

## 実機受入が必要な項目

Widgetの実機ランチャー配置、Widgetのサイズ変更・完了／復元・時間計測、アクセシビリティ許可後の集中制限、実端末の戻るキー、およびPlay署名済みリリースは、端末と署名環境に依存するため本リポジトリのGitHub Actionsビルド後に確認する。
