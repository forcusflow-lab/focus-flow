# Focus Flow プロダクト仕様書

## 1. 目的と基本原則

Focus Flowは、**Todo・習慣・集中制限**を一つの「今日の実行リスト」にまとめ、必要な行動を完了するまで選択済みのAndroidアプリを制限できるローカルファーストの生産性アプリである。日常的な記録、集中の開始、振り返りまでを、片手で理解・操作できる一貫した導線として提供する。

> すべての画面は、最初に「今やること」、次に「なぜ必要か」、最後に「設定や詳細」を示す。操作結果は即時に画面へ反映され、保存済みデータとWidget表示は同じ状態を参照する。

## 2. ドメインモデル

| 概念 | 主な属性 | 正式な役割 |
|---|---|---|
| Todo | 件名、メモ、優先度、期限、必須、サブタスク、完了状態 | 一回で終える行動。完了は親Todoのチェック操作でのみ決定する。 |
| サブタスク | 件名、完了状態 | Todoを分解する一次階層のチェック項目。親Todoの完了とは独立し、進捗だけを表示する。 |
| 習慣 | 件名、色、週目標、必須、進捗単位、日次記録 | 日ごとに記録する継続行動。チェック、回数、時間の三種類を扱う。 |
| 集中制限 | 選択アプリ、必須項目、時間帯、厳格モード | 必須条件が残る間だけ選択アプリの利用を抑止するAndroid機能。 |
| Widget | 今日の必須Todo・習慣、完了表示、テーマ、透明度 | 本体を開かずに今日の状態を確認・操作するホーム画面入口。 |

## 3. 必須・期限・進捗の判定

| 条件 | Today・Widgetでの表示 | 集中制限の解除条件 |
|---|---|---|
| 手動で必須にしたTodo | 必須として表示 | 常時必須、または指定時間帯で必須 |
| 期限が今日以前で未完了のTodo | 必須として表示 | 常時の解除条件 |
| 完了済みTodo | 表示設定に応じて非表示または取り消し線表示 | 解除条件から除外 |
| 必須の習慣 | 必須として表示 | 当日の目標が達成されるまで解除条件 |
| 通常の習慣 | 習慣タブに表示 | 制限条件に含めない |

期限切れは、未完了かつ期限が当日より前のTodoに対する表示状態である。期限が当日のTodoは「今日まで」とし、期限がないTodoには期限メタデータを表示しない。必須表示は日本語では必ず**「必須」**と全文を表示し、カード内で切り詰めない。

## 4. 画面・導線仕様

| 画面 | 主目的 | 主操作 | 戻る／遷移の要件 |
|---|---|---|---|
| Today | 今日の必須Todo・習慣を処理する | 完了、習慣記録、詳細表示、完了一覧切替 | カードは対応する詳細フォームを開く。完了操作は詳細へ遷移しない。 |
| Todo | Todoを追加・並べ替え・完了する | 追加、完了、詳細編集、サブタスク展開 | Widgetからの対象指定は該当Todoの詳細フォームを開く。 |
| 習慣 | 習慣を当日記録する | チェック、回数、時間開始・停止、詳細編集 | カード本体は詳細フォームへ遷移し、Chevronだけがカード内詳細を開閉する。 |
| メモ | 後で整理する情報を記録する | 作成、編集、Todoへ追加、削除 | Todoへ追加した際は本文をTodoメモとして引き継ぐ。 |
| 振り返り | 週次の完了状況を理解する | 指標・進捗の確認 | 数値はTodoの完了日と習慣の当日記録から導出する。 |
| 設定 | 集中制限、表示、Widget、通知、Plusを設定する | スイッチ、選択、時間帯編集、端末設定起動 | 内部パネルではAndroid戻る操作で設定ホームへ戻る。 |
| その他 | 補助画面へ移動する | 振り返り、設定、法務、サポートを開く | すべて有効な遷移先を持つ。 |
| 法務・プライバシー・サポート | 利用条件、データ取扱い、支援情報を確認する | 戻る、外部サポート導線 | アプリを終了させず、Stack内で表示する。 |

## 5. Todoとサブタスクの操作仕様

Todoカードは、チェック領域、件名、必須ピル、メモ・期限、サブタスク進捗を読み取り順に表示する。カード本体は詳細フォームを開き、チェック領域は親Todoの完了・未完了を切り替える。サブタスクがある場合だけ区切りとChevronを表示し、初期状態は閉じる。Chevronとサブタスクのチェックはカード遷移イベントを伝播しない。

Todo編集フォームでは、サブタスクの件名をタップしてインライン編集し、既存の「変更を保存」で親Todoと一緒に保存する。削除は詳細フォームの確認付き操作から実行し、カード一覧に削除アイコンは置かない。

## 6. 習慣の操作仕様

習慣のチェック型は当日の完了を切り替える。回数型は増減操作で日次進捗を更新し、目標到達時に当日完了とする。時間型は開始・停止・再開を保持し、再開後も蓄積済み時間を引き継ぐ。時間目標を満たすまでは、開始時刻と累積時間から残り時間を導出する。

習慣カードはカード本体から詳細フォームを開く。カード内の詳細展開はChevronのみで切り替え、曜日、回数、時間操作は展開後の詳細面に閉じ込める。削除は習慣編集フォームまたは明示的な確認付き操作から実行し、誤タップを避ける。

## 7. 集中制限・Androidネイティブ仕様

集中制限は、アクセシビリティサービスが選択済みアプリの前面化を検知して適用する。未完了の必須条件があり、常時または現在有効な時間帯のルールに対象アプリが含まれる場合、全画面の遮断UIを出す。遮断UIの「今日の項目を確認する」はFocus FlowのToday画面を一度だけ開き、再遮断を避ける短時間の抑止を伴う。

厳格モードは、Focus Flow内の通常操作で集中制限を誤ってオフにすることを防ぐ補助である。Androidのシステム設定、強制停止、端末管理機能、アプリ削除を制御するものではない。この制約は設定・遮断UI・プライバシー情報で一貫して説明する。

## 8. Widget仕様

Widgetは一つの静的RemoteViewsレイアウトだけを使用する。AdapterView、`layout_weight`、`0dp`依存の幅・高さを使用せず、追加時と更新時に同じ安全な経路を通す。表示候補はTodayと同じ有効必須Todo・習慣から生成し、同じIDと種類の重複を除去する。

各行は、チェック領域、件名、必須ピル、メタ情報の順に表示する。Todoのメタ情報にはメモ有無、期限、サブタスク進捗を含める。習慣のメタ情報には週進捗、連続記録、回数・時間操作状態を含める。チェック・復元・回数・時間操作はアクションキューへ保存され、本体がアクティブになった時に一回だけ同期する。

## 9. 表示・アクセシビリティ仕様

アプリテーマ、明暗モード、文字倍率、フォントはすべての画面とWidgetで同じ表示設定を参照する。テキストはテーマ由来のコントラスト色を使用し、ハードコードされた明色・暗色のみの指定を避ける。カード内で固定幅となる要素は、必須ピルやチェック領域のみに限定し、件名・説明・メモは折り返しまたは十分な可用幅を確保する。

各操作可能要素には役割、状態、説明を与える。チェック操作は44dp以上のタップ領域を持ち、カード本体操作とはイベントを分離する。モーダルはAndroid戻ると背景タップで閉じ、設定内パネルは設定ホームへ戻る。
