# Focus Flow：Publish機能でのAndroid実機テスト手順

## この手順で行うこと

この手順では、Manusの**Publish**機能でFocus FlowのAndroidパッケージを生成し、自分のAndroid端末へインストールして、Todo・習慣・アプリ制限・安全停止・ウィジェットを確認します。ここでのPublishはGoogle Playへの審査提出ではありません。Google Play Consoleへの登録や一般公開は、この手順では行いません。

| 項目 | 使用する内容 |
| --- | --- |
| 使用する版 | 最新チェックポイント `cea13203` |
| 対象端末 | Android 7.0以上の実機 |
| 確認する主機能 | Todo、習慣、アプリ制限、10分安全停止、ホーム画面ウィジェット |
| 注意 | アプリ制限はAndroid専用です。iPhoneでは利用できません。 |

## 1. Publishを開始する

1. ManusのFocus Flowプロジェクトを開きます。
2. 右側の管理パネル上部にある**Publish**を押します。
3. 表示されるビルド開始画面で、Android向けパッケージの生成を選びます。実機確認が目的なので、まずはテスト用のAndroidパッケージを選択してください。
4. ビルドの完了を待ちます。完了後のカードにAPKの取得ボタンまたはダウンロードリンクが表示されます。
5. APKをAndroid端末へダウンロードします。PCでダウンロードした場合は、USB、Google Drive、Files by Googleなどで端末に移してください。

> ビルド中にページを閉じても、プロジェクトへ戻ればビルド結果のカードから状態を確認できます。Google Play Consoleには、この段階では何も送信されません。

## 2. Android端末へインストールする

1. Android端末でダウンロード済みのAPKを開きます。
2. 初めてブラウザやファイル管理アプリからAPKを入れる場合は、Androidの案内に従い、**この提供元からのアプリを許可**をオンにします。
3. **インストール**を選び、完了後に**開く**を押します。

すでにFocus Flowが入っていて「アプリはインストールされませんでした」と表示される場合、以前のAPKが別の署名で入っている可能性があります。端末内の旧Focus Flowをアンインストールしてから、もう一度APKを開いてください。Todo・習慣・メモは端末内に保存されるため、アンインストール前に必要な内容を確認してください。

## 3. 最初の5分で確認すること

アプリを開いたら、次の順で設定します。

1. **Today**で「Add a must-do task」を選び、短い必須タスクを1件作成します。例として「Focus Flow test」と入力します。
2. **Habits**で必須習慣を1件作成するか、最初の確認だけなら必須タスク1件だけを使います。
3. **Manage → Settings → App limits**を開きます。
4. 表示されるアクセシビリティの説明を読み、同意してAndroid設定を開きます。
5. Android設定のアクセシビリティ一覧から**Focus Flow**を選び、サービスを許可します。端末によっては「制限付き設定を許可」も必要です。
6. Focus Flowへ戻り、**Refresh status**または状態確認を押してAccessibilityが**On**になっていることを確認します。
7. App limitsをオンにし、制限対象としてテスト用に1つだけアプリを選びます。大切な連絡・決済アプリはテスト対象に選ばないでください。

## 4. アプリ制限を確認する

1. 必須タスクを未完了のまま、制限対象に選んだアプリを開きます。
2. Focus Flowの制限画面が表示され、「Review today’s must-dos」と「Pause limits for 10 minutes」が見えることを確認します。
3. **Review today’s must-dos**を押すとFocus Flowへ戻ることを確認します。
4. 必須タスクを完了にします。
5. もう一度制限対象アプリを開き、通常どおり開けることを確認します。

| 確認項目 | 期待する結果 |
| --- | --- |
| 必須項目が未完了 | 選択アプリを開くと制限画面へ戻る |
| 必須項目を完了 | 選択アプリを開ける |
| 10分安全停止 | 誤設定時でも一時的に選択アプリを開ける |
| 設定のDevice check | Accessibilityと省電力状態を確認できる |

## 5. 時間帯とウィジェットを確認する

**時間帯ルール**では、すぐ確認できる開始時刻・終了時刻を設定します。時間外ではApp limitsが休止し、時間内かつ必須項目が未完了のときだけ選択アプリが制限されることを確認してください。

**ホーム画面ウィジェット**は、Androidのホーム画面を長押しして**Widgets**を開き、Focus Flowを追加します。必須項目を完了・未完了に切り替えた後、ウィジェットの進捗や制限状態が更新されることを確認してください。

## 6. 問題が起きたとき

アプリ制限が動かない場合は、Focus Flowの**Manage → Settings → Device check**を開き、AccessibilityがOnか、省電力・バックグラウンド制限が問題になっていないか確認します。FAQ & supportの**Report a problem**には、端末・Android API・権限・安全停止状態を含めた報告テンプレートがあります。タスク名やメモ本文などの個人情報は、報告へ含めないでください。
