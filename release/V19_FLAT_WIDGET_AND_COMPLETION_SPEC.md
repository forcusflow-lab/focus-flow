# Focus Flow v19 フラットWidget・テーマ・完了表示再設計仕様

## 1. 受入結果と改修の目的

v18の実機受入では、編集シートの保存CTA安全領域（R01）、完了／復元時の安定順序とTodoの縦区分（R05）、Today／Widget表示Switchの独立性・整列（R07）が合格した。一方で、期限当日以前Todoを作成・編集したときに必須チェックが自動選択されないこと（R02）、アプリ本体とWidgetのテーマ面・アクセント・文字の統一感が弱いこと（R03）、Widgetの角丸・カード間隔・ヘッダー密度（R04）、完了済み表示制御の分かりにくさと動作不整合（R06）が不合格となった。

v19では、Todoを「**一度チェックして完了する項目**」、Habitを「**回数・時間・繰り返しを継続記録する項目**」として明確に分離する。Widgetは角丸カードを重ねた見た目を廃止し、ホーム画面で読み取りやすい、見出しと連続行からなるフラットな実行リストに再設計する。ユーザーが示した外部アプリの画面は参考として扱い、Focus Flowのブランド色・情報構造・操作制約に合わせて再構成する。

| v18受入 | 判定 | v19での扱い |
|---|---|---|
| R01: 編集シート保存CTA | 合格 | 回帰確認のみ |
| R02: 期限・有効必須 | 不合格 | 期限当日以前の自動必須選択と全導線同期を実装 |
| R03: 全テーマ可読性・統一性 | 不合格 | 本体とWidgetの役割別テーマトークンへ統一 |
| R04: Widget外観・リサイズ | 不合格 | 角丸なし・間隔なしの連続リストへ再設計 |
| R05: 順序・Todo縦区分 | 合格 | 回帰確認のみ |
| R06: 完了済み表示 | 不合格 | 設定Switchを削除し、各一覧に直接操作を設置 |
| R07: Switch整列・独立性 | 合格 | 設定Switch撤去後は置換仕様を検証 |

## 2. 情報設計と状態遷移

### 2.1 Todoの期限と必須

Todoの期限が**今日または過去日**になると、編集シートの必須チェックは自動でオンとなる。これは「期限による有効必須」の見える化であり、手動で必須にしたTodoと同じPill、Today表示、Widget表示、集中制限解除条件を使う。期限を明日以降または未設定へ変更した場合は、ユーザーが手動で必須にした状態だけを残し、期限起点の自動必須は解除する。

| Todoの状態 | 編集シートの必須チェック | 一覧／WidgetのPill | 集中制限・Today |
|---|---|---|---|
| 手動必須、期限なし／未来 | オン | 必須 | 必須として扱う |
| 今日・過去が期限、手動必須でない | **自動オン** | 必須 | 必須として扱う |
| 未来が期限、手動必須でない | オフ | 表示なし | 通常Todo |
| 完了済み | 完了状態を維持 | 完了表現を優先 | 解除条件から除外 |

### 2.2 TodoとHabitの完了基準

Todoから回数・時間・繰り返し・サブタスクなどの達成条件を外す。Todoの状態は未完了／完了だけとし、行頭チェックで即時に変更できる。既存データにこれらの旧属性が残っても、Todoの完了可否・表示・Widget操作では参照しない。回数、計測、曜日、連続記録はHabitだけが提供する。

### 2.3 完了済み表示

設定画面にあったToday／Widgetの完了済み表示Switchを削除する。Today、Todo、Habitの各一覧画面のセクション見出し近くに、現在の表示状態を明記したコンパクトな操作を置く。

| 現在状態 | 表示する操作 | 操作後 | 保存 |
|---|---|---|---|
| 完了済みを隠す | `完了済みを表示` | 完了済みセクションを同じ画面に展開 | 画面内の一時状態のみ |
| 完了済みを表示 | `完了済みを非表示` | 完了済みセクションを畳む | 画面を離れると非表示へ戻る |
| Widget | ヘッダー／余白のタップ | Todayを`completed=1`で開く | Widgetの設定値は持たない |

この方針では、一覧で必要なときだけ完了済みを確認でき、設定画面を探して永続状態を理解する必要がない。完了済みは画面の主目的ではないため、初期表示は非表示とする。

## 3. 視覚設計

### 3.1 テーマの役割分担

テーマは単に背景色を替えるのではなく、画面全体で同じ役割が同じ意味を保つようにする。背景は低彩度の土台、リスト面は背景から十分に分離した中立surface、主要操作はテーマのprimary、必須は一貫した警告寄りaccent、完了は低彩度のsuccessという役割に固定する。Habitの種別色は補助的な左レールまたは小アイコンに限定し、カード全体の面色を競合させない。

| 役割 | 本体 | Widget | 禁止する表現 |
|---|---|---|---|
| 背景／ヘッダー | `background`／`elevated` | Widget背景とヘッダーで共有 | ライトテーマなのに濃紫面、テーマ外の固定色 |
| 項目面 | `surface` | 連続行の`surface` | 項目ごとに異なる大きな濃色カード |
| 本文／補足 | `text`／`muted` | 高コントラストの同一役割色 | accentと同化する淡い本文 |
| 必須 | warning系Pillと短い`必須` | 同じPill | 背景と区別できない色、Pillの過剰な彩度 |
| 完了 | 取り消し線＋低彩度 | チェック済み＋低彩度 | 文字だけを薄くして読めなくする表現 |

### 3.2 Widgetのフラット連続リスト

Widgetはカードの角丸、カード間の空白、カードごとの外枠を廃止する。外側は必要最小限の背景面、内部は高さを増やした見出しと、境界線だけで区切る連続行で構成する。これは小さなホーム画面領域で、タイトル・必須・チェック・本文を同じ列に揃え、視線移動を抑えるためである。Android公式が推奨する複数のresponsive layoutを維持し、small／medium／largeで1／2／3行を切り替える。[1]

| Widget要素 | v19仕様 |
|---|---|
| 見出し | 高さ52dp。`今日の項目`と集中制限の状態を左揃えで表示し、背景透過率と連動する。角丸・個別枠なし。 |
| 実行行 | 高さ48dp。カード間隔0dp、角丸なし、横一杯。左4dpの種別アクセント、44dp以上の行頭完了操作、必須Pill、1行タイトル、短い補足を一定位置へ揃える。 |
| 区切り | 行間の1dp dividerのみ。最終行の下にも外枠を置かない。 |
| サイズ | small=1行、medium=2行、large=3行。サイズ変更時に同じ情報配置を保ったまま行数だけを変える。 |
| タップ | 行頭のチェック／Habit操作は専用領域、本文は該当項目、ヘッダー・余白はTodayの完了済み一時表示へ遷移する。 |

### 3.3 Widget透過率

設定画面では、背景全体と項目行を**独立した横スライダー**で変更する。操作中に値ラベルを表示し、10%単位で反映する。静的RemoteViewsとの互換性を守るため、Native側では背景色のARGB値だけを10%単位で生成して適用し、禁止している`setFloat`／`setAlpha`には依存しない。文字、チェック、Pillのalphaは変更せず、読みやすさを保つ。タイトルは背景全体と同じ背景透過率を使い、独立した不透明度操作を追加しない。

| コントロール | 範囲・保存値 | Widgetへの適用 |
|---|---|---|
| 背景の透過率 | 0〜100%、10%単位 | Widget外側と見出しの背景面だけ |
| 項目の透過率 | 0〜100%、10%単位 | Todo／Habitの連続行surfaceだけ |
| 文字・アイコン | 固定の高コントラスト色 | alphaを下げず、どの設定でも判読可能にする |

スライダーは連続値を直感的に調整する設定に適し、変更をその場で反映する。[3] 項目は一貫した先頭操作と本文位置を持つ連続リストにする。[2]

## 4. 実装範囲

| 領域 | v19の変更 |
|---|---|
| Todo form／状態 | 期限入力時に有効必須を自動選択し、Todoの旧進捗・時間・繰り返しUIを削除または非表示化する。 |
| Today／Todo／Habit | 設定依存の完了表示を廃止し、各画面の一時的な表示／非表示操作で統一する。 |
| Settings | Today／Widgetの完了済み表示Switchを削除し、Widget設定を二本のスライダーとライブ値表示へ置換する。 |
| テーマ | 6テーマ×light／darkで、面・文字・必須・完了・accentを役割別トークンで統一する。 |
| Android Widget | 角丸drawableを使わないヘッダー／連続行へ置換し、背景／行の10%単位ARGB透過、responsive 1／2／3行、専用タップ領域を維持する。 |
| 永続化・同期 | `widgetBackgroundOpacity`と`widgetCardOpacity`を別キーで保存し、Native Widget同期payloadへ送る。従来のWidget完了済み表示設定は移行時に無効化する。 |
