# Focus Flow 本人用 v9 実機受入チェックシート

## 前提

対象は本人用 `com.app.focusflow.personal`、`versionCode 9` の署名APKである。APKはこのチェックシートの全項目が合格するまで共有対象にしない。各ケースでは、**結果が分かるスクリーンショット**を残し、不合格なら同じケースの再実施ではなく修正・再ビルド後に最初から確認する。

## 判定表

| ID | 操作・状態 | 合格条件 | 記録 |
|---|---|---|---|
| W-01 | ホーム画面から小・標準・大Widgetを追加 | 「ウィジェットを表示できません」が出ず、ヘッダーと内容または空状態が表示される | 3枚 |
| W-02 | Todo/習慣を0件、1件、2件にする | 重複・余分な行・途中で切れた行がない | 3枚 |
| W-03 | 長いタイトル、必須、通常、時間帯ありを混在 | `必須`が完全に読め、通常に不要なタグがなく、補足が重ならない | 1枚以上 |
| W-04 | 背景濃さ0/25/50/75/100%、ライト/ダーク | 本文、補足、チェック、境界が読め、透過で本文・チェックまで薄くならない | 10枚 |
| W-05 | アプリ文字サイズを小/標準/大にする | 3サイズすべてで文字切れ・重なり・過大チェックがない | 3枚 |
| W-06 | 上段/下段の完了・復元、本文、ヘッダーを順にタップ | 各行だけが変化し、本文は該当詳細、ヘッダーはTodayを開く | 操作録画または連続スクリーンショット |
| A-01 | 表示と言語をライト/ダーク、各テーマ・フォント・文字サイズで開く | テーマ見本、選択肢、説明、Widget設定が読め、白面＋白文字や淡い選択肢がない | 代表6枚 |
| A-02 | Today/Todo/習慣/メモ/振り返り/その他/設定を空・複数・完了で確認 | カード、入力面、モーダル、必須・完了・無効状態が判読できる | 画面別 |
| N-01 | 戻る、Deep Link、遮断画面の「項目を確認」、起動を確認 | 直前画面へ戻り、Deep Link/遮断導線はTodayまたは該当詳細へ正しく遷移する | 操作録画または連続スクリーンショット |

## 受入判定

| 状態 | 条件 |
|---|---|
| 合格 | 上表の全項目について、表示・操作・遷移の不具合がなく、必要な証跡を記録できた場合 |
| 保留 | 証跡が不足している、又は実施できていない項目がある場合 |
| 不合格 | Widget追加不能、文字切れ、低コントラスト、状態混線、誤遷移、クラッシュのいずれかが1件でもある場合 |

> **不合格又は保留の間は、APKの添付、ダウンロードURL共有、Google Play内部テストへの配布を行わない。**
