# Focus Flow：Android互換性・実機テスト方針

> **公開時の約束**：Focus Flowは、Androidのアクセシビリティサービスを利用して、ユーザーが選んだアプリが前面に開いたことを検出します。OS・メーカー・省電力設定により動作が制限される場合があるため、制限が不確実なときにユーザーを閉じ込めないことを優先します。

## 対応範囲

| 項目 | 方針 |
| --- | --- |
| 最低Android版 | Android 7.0（API 24）以上 |
| テスト優先OS | Android 10、12、13、14、15、16相当の実機またはエミュレーター |
| CPU ABI | `armeabi-v7a`、`arm64-v8a` |
| 必須機能 | アクセシビリティサービスをユーザーが明示的に有効化した場合のみ、選択アプリの前面化に対して集中ルールを適用する。 |
| 非保証事項 | OEM独自の省電力・タスクキラー、OSのアクセシビリティ制限、端末管理ポリシーに起因する常時動作。 |

Androidはアプリを「Restricted」に設定するとバックグラウンド実行を抑制し、端末メーカーごとに制限の詳細が異なることがあります。[1] Focus Flowはこれを隠さず、アプリ内の端末診断で状態を確認できるようにします。

## フェイルセーフ

| 状況 | Focus Flowの動作 |
| --- | --- |
| アクセシビリティが無効 | アプリ制限を適用しない。設定画面で有効化手順を案内する。 |
| 集中ルールがオフ | アプリ制限を適用しない。 |
| 端末のバックグラウンド制限を検出 | 警告とアプリ情報への導線を表示する。無条件に省電力最適化を無効化するよう強制しない。 |
| 誤制限・緊急時 | ネイティブ制限画面から**10分だけ安全停止**できる。安全停止中はアクセシビリティサービスが制限を適用しない。 |
| ルール状態の読み取り失敗 | 制限を適用しない。 |

Androidのバックグラウンド最適化では、ユーザーがアプリを制限状態にするとバックグラウンド作業が停止し、予期しない動作になることがあります。[1] そのため、Focus Flowは「動かなければより強く制限する」設計ではなく、「状態を表示し、必要に応じてユーザーが設定を確認できる」設計を採用します。

## クローズドベータ実機マトリクス

| 優先度 | 端末例 | OS | 検証する代表シナリオ | 合格基準 |
| --- | --- | --- | --- | --- |
| P0 | Google Pixel | 最新安定版 | 初期設定、権限オン／オフ、Todo達成、日課時間帯、10分安全停止 | 誤制限・解除不能・クラッシュがない。 |
| P0 | Samsung Galaxy | Android 13以降 | バッテリー最適化の標準／制限状態、画面ロック後、再起動後 | 診断が状態を説明し、制限不能時も利用者が詰まらない。 |
| P1 | Xiaomi / Redmi | Android 12以降 | 独自の省電力設定後、アプリ切替、長時間未使用後 | 問題を再現・案内でき、10分安全停止が常に使える。 |
| P1 | OPPO / OnePlus | Android 13以降 | バックグラウンド制限、日課の開始・終了時刻 | 時間帯の適用と解除がルールどおり。 |
| P2 | Android 10〜12の低〜中価格帯端末 | 対象OS | 小メモリ、表示倍率、文字サイズ、回転なしの縦画面 | 画面が読め、基本フローが完了できる。 |

## 1台あたりのテスト手順

1. Focus FlowをGoogle Play内部テストからインストールします。
2. 必須Todoを1件作成し、制限対象アプリを1つだけ選びます。
3. アクセシビリティの説明を読み、Android設定でFocus Flowを有効化します。
4. 未完了状態で制限対象アプリを開き、Focus Flowの制限画面へ戻ることを確認します。
5. Todoを完了し、対象アプリが開けることを確認します。
6. 日課時間帯外・時間帯内・日付をまたぐ時間帯を確認します。
7. バッテリー設定を標準・制限に切り替え、アプリ内診断と実際の動作が矛盾しないことを確認します。
8. 制限画面の「10分だけ安全停止する」を使い、対象アプリへ一時的に戻れることを確認します。
9. Androidバージョン、メーカー、モデル、再現手順、スクリーンショットをベータ報告へ記録します。

## 公開判断

正式公開前に、P0の2系統以上でクリティカルな解除不能問題がないことを確認します。P1の端末で安定しない場合は、ストア説明とアプリ内診断で対応範囲を明示し、問題端末向けの設定案内を追加します。**「すべてのAndroid端末で完全動作する」とは宣伝しません。**
