# Focus Flow — 無料版、Plus、早期完了の商品仕様

**基準日:** 2026-08-18  
**アプリ名:** Focus Flow

Focus Flowは、無料利用者が基本的な計画、言語、外観、アクセシビリティ機能を使えることを前提とします。Plusはアプリ名ではなく任意のサブスクリプション機能名です。時間前の完了は、Plus加入の有無に関係なく、対象項目ごとの消費型商品として扱います。

| 区分 | 無料版 | Focus Flow Plus |
|---|---|---|
| Todo | 2件まで | 無制限 |
| 習慣 | 2件まで | 無制限 |
| メモ | 2件まで | 無制限 |
| 制限対象アプリ | 全ルール合計5件まで | 無制限 |
| 言語・外観・文字・ウィジェット | 無料 | 無料 |
| 保存済みテーマセット | 利用不可 | 利用可能 |
| 分を目標にした項目 | 設定時間の経過後に完了 | 同じ |
| 設定時間前の早期完了 | 1回ごとの消費型商品 | 同じ |

## 商品一覧

| 種別 | 商品ID | ストア種別 | 用途 | 復元 |
|---|---|---|---|---|
| Plus | `focus_flow_plus` | 自動更新サブスクリプション | 件数上限の解除とテーマセット保存 | 対象 |
| 早期完了 | `focus_flow_early_complete_100` | 消費型の1回限り商品 | 時間管理項目1件を設定時間前に完了 | 対象外 |

Plusの価格、請求期間、地域、オファーはストアで設定し、アプリではストアから取得した実価格だけを表示します。早期完了商品は日本では¥100を基準とし、他地域ではストアの現地価格を表示します。消費型商品の登録・テスト手順は [ONE_TIME_UNLOCK_PRODUCT_SETUP_JA.md](./ONE_TIME_UNLOCK_PRODUCT_SETUP_JA.md) を参照してください。

## 受入基準

1. 無料利用者は上限を超える作成・アプリ選択時に、データを失わず明確な案内を受ける。
2. Plusの有効化・失効で既存のTodo、習慣、メモ、集中ルール設定を削除しない。
3. 分を目標にした項目は、計測開始から設定時間の経過前には完了扱いにならない。
4. 早期完了は、購入成功・トランザクション確定後に対象項目だけへ付与される。
5. Androidでは消費処理により同じ早期完了商品を再購入できる。Google Playは、消費型商品の購入後に消費処理を行うよう案内している。[1]
