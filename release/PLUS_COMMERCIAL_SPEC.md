# Focus Flow Plus — 商用化仕様

**基準日：2026年8月15日。** 本仕様は、Focus Flowをクローズドベータから公開・収益化へ移行するためのプロダクト境界と課金実装契約です。価格は仮説であり、Play Consoleの商品設定とライセンステストが完了するまで、利用者へ購入可能であると表示しません。

## 商品方針

Focus Flowの購入理由は、広告除去や安全機能の解放ではなく、日々の仕組みを継続的に自分の生活へ合わせるための拡張性です。無料版は、ユーザーが「今日の必須事項を終えるまで、選んだ注意散漫なアプリを開かない」という中核成果を体験できなければなりません。

| 区分 | 無料版 | Focus Flow Plus |
| --- | --- | --- |
| 日々の計画 | Todo、習慣、メモ、期限、サブタスク、進捗目標 | 同じ。中核の計画機能を削らない。 |
| 外観の個人化 | ミスト・スレートの標準テーマ、標準の文字サイズ、ウィジェット色の選択 | エバーグリーン、オーシャン、オーキッド、サンライズのアプリテーマ、OS外観連動、名前付きテーマセット、ウィジェット別文字サイズ。 |
| アプリ制限 | 1つの有効な日課ルール、1つの選択対象アプリ、明確な解除条件、安全停止 | 複数の日課ルール、複数の選択対象アプリ、より多い日課テンプレート。 |
| 振り返り | 現在の週次進捗 | 詳細な週次傾向、反復テンプレート、将来の拡張振り返り。 |
| 安全性・サポート | Accessibility開示、設定解除、安全停止、FAQ、データ削除 | 同じ。安全停止やプライバシーは有料化しない。 |

初期の販売仮説は、**月額USD 4.99**と**年額USD 29.99**です。これらは表示価格ではなく、Play Consoleで地域別の価格、税、利用可能国、オファーを確認するための出発点です。アプリ内の価格表示は、必ずGoogle Playから返る商品詳細を使用します。[1]

## 商品IDとPlay Console設定

| 項目 | 推奨値 | 備考 |
| --- | --- | --- |
| Subscription product ID | `focus_flow_plus` | 一度公開後は変更せず、明確な名称を維持する。 |
| Monthly base plan ID | `monthly` | 自動更新。地域別価格はConsoleで設定する。 |
| Annual base plan ID | `annual` | 自動更新。月額との比較表示は実際の価格・通貨で計算する。 |
| Trial / intro offer | 初期は未設定 | 無料版価値と継続率が確認できた後に限定オファーをテストする。 |
| 対象地域 | 英語圏から段階導入 | サポート・税務・ポリシー対応が確認済みの国のみ。 |

## 課金状態の実装契約

Google Play Billingを接続するリリースでは、以下の状態を明示的に扱います。UIは、カタログや購入状態を取得できないときに、購入成功やPlus利用可能を推測してはなりません。

| 状態 | 意味 | UI・権利の扱い |
| --- | --- | --- |
| `unavailable` | ベータ、未設定のビルド、Play外インストール | 購入UIを表示しない。無料版を通常利用できる。 |
| `loading` | 商品または既存購入を照会中 | ボタンを無効化し、現在の権利を変更しない。 |
| `eligible` | 商品を取得済み、Plus権利なし | 実際の価格・期間・管理方法を示して購入を開始できる。 |
| `pending` | Playが保留購入を返した | Plusは未付与。処理中の理由と再確認操作を提示する。 |
| `active` | 購入確認・付与・承認済み | Plus機能を有効化し、管理・復元導線を表示する。 |
| `inactive` | 有効な購入が見つからない、または失効 | Plus機能を無料版に戻し、既存ユーザーのデータを削除しない。 |
| `error` | ネットワークまたはBilling接続失敗 | 現在の非破壊状態を保ち、再試行だけを提示する。 |

購入後は、購入更新を処理し、既存購入を照会し、購入を承認した後にのみPlusを付与します。アプリ再開時と「購入を復元」操作時にも既存購入を照会します。Google Playの定期購入管理画面へ遷移する設定導線を用意します。[1]

テーマを選択する画面は、商品カタログを取得できないビルドでは価格や購入成功を表示せず、「未設定」と明示します。`eligible`状態に限りGoogle Playから返された価格で購入を開始し、`active`以外ではプレミアムテーマ、保存テーマセット、OS外観連動、ウィジェット文字サイズを有効化しません。これにより、スクリーンショットやテスト用データだけで有料権利が付与されることを防ぎます。

## 販売を開始するための受入条件

1. Android制限のP0問題、復帰不能、無限リダイレクトが解消され、複数実機で安全停止を確認する。
2. Google PlayのAccessibilityService申告、Data safety、公開プライバシーポリシー、ストア説明が最終AABと一致する。[2] [3]
3. Consoleで`focus_flow_plus`の各ベースプランを作り、対象パッケージ・ライセンステスター・テストトラックを接続する。
4. 新規購入、月額/年額、保留、復元、キャンセル、失効、接続失敗を実機で記録する。
5. 返金、税務、問い合わせの発行主体と監視可能なサポート窓口を確定する。

上記が完了するまでは、**クローズドベータを無料で運用**し、Plusはユーザー調査・内部準備にとどめます。非機能の購入ボタンや、実装されていない値引きを公開しません。
