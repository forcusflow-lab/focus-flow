# Focus Flow v12 — 改修・UI/UXレビュー概要

> **対象**：Focus Flow Android中心のv12全面改修。本文書は、今回実施した仕様設計、UI/UX変更、ネイティブ連携の修正、自動検証、および実機で残る受入項目をまとめたレビュー資料です。

## 1. 今回の目的

今回の改修では、個別の見た目調整に留めず、Focus Flowを「初めて使う人から日常的に使う人まで、迷わず今日の行動を決められるアプリ」に近づけることを目的としました。特に、Androidの集中制限とウィジェットを中心に、**時間帯に沿ってやるべきことを明確にすること**、**画面遷移で迷子にならないこと**、**完了・復元を誤操作しないこと**を重視しています。

| 設計原則 | 今回の反映内容 |
|---|---|
| 一画面一目的 | Todayは「今やる」「この後」「今日のリスト」に整理し、設定は目的別の入口を維持します。 |
| 平易な言葉 | 「管理」など抽象的な表現を「その他」へ整理し、法務・サポート・FAQの戻る先も統一しました。 |
| 誤操作防止 | チェック操作と詳細遷移を分離し、Widgetの完了・復元は専用48dp領域に限定しました。 |
| 状態の見える化 | 完了、時間帯外、時間帯内、次の予定を文字・色・補助ラベルで区別します。 |
| Androidの信頼性 | 遮断画面、Widget、Deep LinkのURL形式を共通化し、ネイティブ生成で検証します。 |

## 2. 新機能：時間帯必須

Todoと習慣に、従来の「必須」に加えて**「この時間帯に必ず取り組む」**設定を追加しました。これは、設定画面で登録した時間帯を選び、その時間の間だけ集中制限の解除条件になる仕組みです。

| 状態 | Todayでの表示 | 集中制限・遮断 | Widgetでの表示 |
|---|---|---|---|
| 常時必須 | 必須の今日の項目 | 未完了なら解除条件 | 必須ラベル |
| 時間帯前 | 「この後」に予定時刻を表示 | まだ解除条件に含めない | 時間帯ラベル |
| 時間帯中 | 「今やる」に表示 | 未完了なら解除条件 | 時間帯ラベル |
| 時間帯後 | 今日の通常リストへ整理 | 解除条件に含めない | 時間帯ラベル |
| 完了 | 完了表示・取り消し線 | 解除条件から外す | 完了／復元操作 |

既存の必須項目は、安全性を優先して**常時必須**として自動移行します。割り当て済みの時間帯を設定から削除する場合も、意味が失われないよう常時必須へフォールバックします。日をまたぐ時間帯も判定対象です。

## 3. Today・Todo・習慣・Widgetの変更

Todayは、すぐに行動する項目を最上位に置き、開始前の時間帯必須を「この後」として分けました。Todoと習慣のカードには、必要な場合だけ実行時間帯を補助表示します。完了済みを残す設定では、行全体を過度に薄くせず、読みやすいグレーと明瞭な取り消し線を使います。

Android Widgetは、Todoと習慣を一つの一覧で扱います。視覚上のチェックは小さく維持しつつ、操作領域は48dpへ広げました。チェックは完了または復元のみ、行本文は該当Todo／習慣の詳細、Widgetのヘッダー・余白はTodayを開くという役割分担です。

> **重要な修正**：WidgetのURL生成に、端末によって4スラッシュとして解釈される余地があり、Unmatched Routeを起こす可能性がありました。すべてのWidget Deep Linkを、authorityを持たない `scheme:///` を基点にしてパスを追加する方式へ統一しました。

## 4. 遮断画面・Deep Link・戻る操作

集中制限中に表示されるAndroidの遮断画面では、「Focus Flowで項目を確認する」操作を**必ずTodayへ戻す**設計に統一しました。WidgetからのTodo／習慣詳細遷移と、遮断画面からのToday遷移は、通常版・本人用Plus APKの双方で同じURL構造を使います。

設定、利用条件、プライバシー、サポートなどの戻る表記は、現在のタブ構成に合わせて「その他へ戻る」に整理しました。過去の抽象的な「管理」表記を削除し、画面間の文脈を保てるようにしています。

## 5. 起動体験と全画面UI/UX

起動時は、アイコン単体を大きく見せるだけの印象を避けるため、ネイティブSplashの色と統一した深緑基調の**全画面ブランド導入**を追加しました。保存済みデータの復元と連動し、準備完了後に短いフェードでTodayへ移ります。人工的な待機時間は追加していません。

全画面レビューでは、Today、Todo、習慣、メモ、振り返り、その他、設定、利用条件、プライバシー、サポート、ヘルプ、公開利用条件、公開ポリシー、起動、Widget、遮断画面、Deep Link、戻る操作を対象にしました。今回の主な修正は次のとおりです。

| 対象 | UI/UX改修 |
|---|---|
| メモ | 空タイトルでも本文由来の名称を表示し、Todo化の意味を視覚ラベルで補強しました。 |
| 振り返り | 現在・次の時間帯の表示を、時間帯必須の仕様と一致するよう整理しました。 |
| その他タブ | 抽象的な「管理」ではなく、設定・サポート・法務へ進む入口として意味を明確化しました。 |
| 設定 | 時間帯を削除する場合、影響する必須項目数と常時必須への移行を明示して確認します。 |
| 利用条件・プライバシー・サポート | 表記と戻る先を「その他」へ統一し、FAQも現在の導線に合わせました。 |
| 完了表示 | カード密度を保ちつつ、完了済みの可読性と復元可能性を改善しました。 |

## 8. 実機で残る受入確認

自動検証とネイティブ生成は通過していますが、Androidホーム画面、アクセシビリティ遮断、実際の起動画面は端末上でのみ最終確認できます。署名済みAPK／AABで下記を通過するまで、完全な実機合格とは扱いません。

1. 起動時に全画面ブランド導入からTodayへ自然に進むこと。
2. 時間帯前・時間帯中・時間帯後で、Todayと集中制限の扱いが設計どおり変わること。
3. 制限アプリの遮断画面から「項目を確認する」を押すと、必ずTodayを開くこと。
4. Widgetのチェックで完了、再チェックで復元し、画面遷移しないこと。
5. Widgetの行本文で該当Todo／習慣、ヘッダー・余白でTodayを開き、Unmatched Routeにならないこと。
6. Todo／習慣本体のチェックが詳細画面を開かないこと。
7. 設定、詳細、モーダルからの戻る操作が直前の文脈へ戻ること。
