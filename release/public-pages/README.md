# Focus Flow 公開ページ雛形

このディレクトリのHTMLは、App Store ConnectとGoogle Play Consoleに入力する**公開HTTPS URL**の元ファイルです。`[SUPPORT_EMAIL]`、`[OPERATOR_NAME]`、`[EFFECTIVE_DATE]` を、実在し継続して監視できる情報へ置き換えてから公開してください。

低コストで公開する場合は、所有するGitHubアカウントのリポジトリにこのディレクトリの内容を配置し、GitHub Pagesを有効にする方法が候補です。独自ドメインは必須ではありませんが、ページURLをストア公開後も維持できるアカウントで管理してください。公開確認後、次のURLを各ストアに入力します。

| ファイル | 使用先 |
|---|---|
| `privacy.html` | App Store ConnectのPrivacy Policy URL、Google Play ConsoleのプライバシーポリシーURL |
| `support.html` | App Store ConnectのSupport URL、Google Play ConsoleのサポートURL |
| `terms.html` | Focus Flow Plusの利用条件URLとして、説明文・審査メモ・サポートページに掲載 |

公開後は、シークレットウィンドウまたは未ログイン状態で3ページへアクセスし、404、ログイン要求、仮文言がないことを確認してください。
