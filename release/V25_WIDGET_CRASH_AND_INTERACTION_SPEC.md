# Focus Flow v25 Widget安定性・操作性能・可読性仕様

## 1. 実機報告と優先度

利用者報告によれば、回数設定を持つHabitをWidget候補へ追加した後にWidgetホストが「ウィジェットを表示できません」と表示した。これはWidget全体を利用不能にするためP0障害とする。過去の添付画像は指定により再閲覧せず、報告本文だけを再現条件とする。

| 優先度 | 受入ID | 課題 | 合格条件 |
|---|---|---|---|
| P0 | V25-R01 | 回数HabitでWidget表示不能 | 未完了/完了、0/途中/達成回数、small/medium/large/expandedの全組合せでRemoteViews例外がなく表示される。 |
| P1 | V25-R02 | Sliderの位置・重さ | Thumb、表示値、保存値を同じ0〜100の値から描画し、範囲外へ視覚的にも論理的にも動かず、ドラッグ中にI/Oを行わない。 |
| P1 | V25-R03 | Todo/Habit詳細遷移の遅延 | 押下後にシートを先に表示し、初期化・Native同期・永続化を後段へ分離する。 |
| P1 | V25-R04 | テーマ別の文字不可視 | 6テーマ×light/darkの本文・補足・入力・操作・Widgetで文字と背景を機械検査し、必要な色を補正する。 |

## 2. 設計

回数HabitのWidget描画では、Providerがレイアウトに存在しないIDへRemoteViews操作を行わないことを最優先する。表示可否の分岐とPendingIntentの設定対象を、静的レイアウトの各行・各操作IDに一対一で対応させる。Widget Providerの描画例外は、個別行を非表示にするだけでWidgetルートを失敗させない。

Sliderはトラック両端にThumb半径を含めた有効範囲を設け、イベント座標をこの範囲へclampした後に0〜100の整数へ換算する。ドラッグ中には一つの軽量なUI値だけを更新し、保存とNative同期はリリース時に一度だけ行う。

詳細シートはユーザー操作で開閉状態を先に確定し、フォーム初期値、集計、Widget同期、永続化をシートの表示フレームから外す。テーマ可読性はprimary・foreground・muted・surfaceの組合せを全テーマで検査し、文字色を背景へ依存しないコントラスト値へ統一する。

## 3. 自動品質ゲート

Widget ProviderとXMLについて、回数Habitの全行ID、controls/timer/counterの表示分岐、RemoteViews禁止構造の不在を検査する。Sliderは0/1/50/99/100、トラック外、tap/drag/releaseを検査する。詳細フォームは先行表示と初期化順を検査し、配色はテーマ全12状態の文字コントラストを検査する。全テスト、型検査、Lint、通常版と本人用のクリーンAndroid生成、署名済みAPKの独立検証を通過した後に実機受入へ進む。
