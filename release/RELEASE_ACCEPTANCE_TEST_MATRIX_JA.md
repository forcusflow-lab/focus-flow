# Focus Flow リリース受入テストマトリクス

**実行者:** アカウント所有者または指名テスター  
**原則:** 各テストは実端末・最終ビルド・実ストア商品で記録する。Todo名・メモ本文・購入アカウント情報は記録しない。

## 基本導線

| 画面・機能 | 操作 | 合格基準 |
|---|---|---|
| 初回起動 | 言語と表示を選び、ホームへ進む | 画面が崩れず、再起動後も選択が保持される。 |
| Todo | 通常Todoと必須Todoを作成・編集・削除する | 期限、優先度、サブタスク、必須状態が保存される。 |
| 習慣 | 習慣を作成し、今日と過去日の表示を確認する | 週間目標・連続記録が画面と振り返りで一貫する。 |
| メモ | メモを作成し、Todoへ変換し、削除する | 無料上限、変換失敗、削除確認が明確に表示される。 |
| 振り返り | 7日分のTodoと習慣を確認する | 件数、進捗、集中ルールの状態が実データと一致する。 |
| 表示設定 | 文字サイズ・配色・ライト/ダークを変更する | 小さい画面でも最後の設定まで到達し、無料で保存される。 |

## 無料・Plus・時間管理

| テスト | 操作 | 合格基準 |
|---|---|---|
| 無料上限 | Todo・習慣・メモを3件目、制限対象アプリを6件目にしようとする | 作成せず、無料上限とPlusの説明が表示される。既存データは失われない。 |
| Plus | 有効なPlusで上限を超えて作成する | 上限なしで作成でき、テーマセットも保存できる。 |
| 時間管理開始 | 分単位の必須Todoまたは習慣を初回タップする | 計測開始が明示され、すぐには完了しない。 |
| 時間管理待機 | 設定時間より前にもう一度完了しようとする | 完了にならず、待機または早期完了の選択肢が表示される。 |
| 時間経過 | 設定時間経過後に確認する | 対象項目だけが完了し、必須項目なら解除条件が再計算される。 |
| 早期完了 | ストア商品を購入、キャンセル、再購入する | 購入成功時だけ対象1件を完了。キャンセルでは不変。消費後に同じ商品を再購入できる。 |

## Android集中ルール・ウィジェット

| テスト | 操作 | 合格基準 |
|---|---|---|
| Accessibility同意 | 説明を読みAndroid設定でサービスをオンにする | 同意前には動かず、同意後の状態が設定画面で明確。 |
| 対象アプリ | 必須項目が未完了のまま選択済みアプリを開く | 設定時間帯内だけ制限画面が表示され、非選択アプリは影響を受けない。 |
| 解除 | 必須項目を完了する | 選択済みアプリが再び開ける。 |
| 停止 | Focus Flow設定でルールをオフ、またはAndroid設定でサービスをオフにする | ユーザー自身が制限を停止できる。 |
| ウィジェット | 5種類のウィジェットを追加し、Todo・習慣を更新する | 進捗と状態が更新され、時間管理項目を早期に完了できない。 |

## ストア・通知・回帰

| テスト | 操作 | 合格基準 |
|---|---|---|
| 通知 | 権限を許可し、毎日の時刻を設定する | 意図した時刻に1日1回だけ届き、許可なしでは送られない。 |
| Plus復元 | 別端末または再インストール後に復元する | 有効な定期購入だけが復元される。 |
| プライバシー | アプリ内のデータ削除を実行する | ローカルデータと集中ルールが削除・停止される。 |
| URL | プライバシー・サポートURLを開く | HTTPS、実在する連絡先、現行の課金・集中ルール説明が表示される。 |
| 画面回帰 | 日本語/英語、最小文字/最大文字、ライト/ダークを確認する | 主要ボタン、本文、下部操作が重ならず、読めてタップできる。 |
