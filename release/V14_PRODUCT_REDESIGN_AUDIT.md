# Focus Flow v14 — 全機能・全画面プロダクト再監査台帳

**目的:** 現在のWidget追加不能・ライトモード本文消失を、局所的な不具合ではなく、仕様から実機受入までの設計契約が不十分だった兆候として扱う。本台帳は、機能追加よりもまず「目的が明確で、操作が予測でき、失敗しても戻れる」ことを基準に、追加・削除・変更を判断する。

## 1. 全体の設計原則

| 原則 | 採用判断 | 設計上の具体化 |
|---|---|---|
| 一操作一結果 | 維持・強化 | チェックは状態だけを変え、本文だけが詳細を開く。操作後に意図しない画面移動を起こさない。 |
| 現在地を失わない | 維持・強化 | Today起点の詳細は閉じる・戻るでTodayへ戻す。設定詳細は設定ホームへ戻す。 |
| 情報密度を目的に合わせる | 変更 | Widgetは「一覧で確認・完了」のための高密度行。本文アプリは可読性を優先し、無意味な装飾カードや重複見出しを作らない。 |
| テーマは意味で定義する | 変更 | 本文・補足・面・境界・操作・無効・完了をセマンティックトークンで扱い、ライト色・ダーク色を個別画面に直書きしない。 |
| ネイティブ機能は追加可能であることが前提 | 追加 | Widget、集中制限、通知は「初回利用できる」「状態更新が反映される」「失敗時に理由が分かる」を受入必須条件とする。 |
| 説明は必要な瞬間だけに置く | 変更 | 長い説明文は設定ホームから除き、権限・危険操作・時間条件のように判断が必要な場面だけに短く表示する。 |

## 2. 画面・機能別の再監査範囲

| 領域 | 主目的 | 変更・確認方針 | 実機受入条件 |
|---|---|---|---|
| 起動・Today | 今日やることを選び完了する | チェックと詳細を分離し、必須・時間帯・通常の優先度を短い階層で示す | 起動、空状態、直接詳細、戻る、完了／復元が文脈を失わない |
| Todo・習慣 | 作成、編集、進捗管理 | 一覧・詳細・フォームの情報階層を共通化。時間帯必須は補助情報として扱う | 長文、未完了／完了、時間未達、無料上限、フォーム、戻るが読める |
| メモ・振り返り | 記録と振り返り | キーボード、空状態、削除確認、データなしの説明を短く維持 | 入力・保存・編集・削除・空状態・ダークテーマが成立する |
| 設定・Plus | 意図に沿う設定変更 | 目的別ホームを維持し、権限・表示・集中制限・データを混在させない | ライト／ダーク、文字サイズ、テーマ、Widget設定、Android戻るが理解できる |
| その他・法務・支援 | 困ったときの情報取得 | 長文の可読性、外部リンク、FAQ、サポート導線を共通ページ化 | 利用条件・プライバシー・ヘルプ・サポートでクラッシュ、読めない文字、戻れない状態がない |
| 集中制限・遮断 | 制限対象からTodayへ安全に戻す | 「項目を確認」は必ずToday。権限・対象アプリ・時間帯を三段階で説明 | アプリ再開時遮断、遮断画面、Today導線、設定復帰が成立する |
| Android Widget | ホーム画面で確認・完了する | Provider追加、更新、テーマ、文字サイズ、チェック、詳細を一つの仕様として扱う | 追加成功、小・中・大、ライト／ダーク、3文字サイズ、行操作が全て成立する |
| Deep Link・戻る | 起点に合う移動 | authorityなしURI、詳細直接遷移、閉じる先を固定する | Widget／遮断／Today／通知の各起点で想定した画面へ着地し復帰できる |

## 3. 追加・削除・変更の判断

| 区分 | 判断 | 理由 |
|---|---|---|
| 追加 | Widgetの「追加可能性」診断と、Provider登録・初期レイアウト・更新状態のネイティブ検証 | Widgetを使う以前にホーム画面へ配置できることが壊れているため。 |
| 追加 | 明示的なWidget用セマンティック配色契約とライト／ダークのコントラスト検査 | アプリパレットの暗黙同期だけでは、本文が背景色に近づく回帰を防げなかったため。 |
| 変更 | Widgetをカード群ではなく、48dp操作領域を持つ高密度リストに限定 | 小さなホーム領域で複数項目を確認する目的に合うため。 |
| 変更 | 全画面の本文・補足・入力の色を共通トークンへ集約 | 画面ごとの固定色によるライト／ダークの読めない状態を減らすため。 |
| 削除 | Widget行ごとの大きい装飾カード、空の補足行、完了後の一時Undo表示 | 情報密度を下げ、チェックと本文の役割を曖昧にするため。 |
| 維持 | Todayからの直接詳細、チェックの遷移なし、遮断画面からToday、本人用APKの別パッケージ | 実機要望と無料版／本人用版の分離要件を満たすため。 |

## 4. リリース阻害条件

次のいずれかが残る限り、通常版をGoogle Play内部テストへ公開しない。

1. ホーム画面のWidgetピッカーで「Focus Flow · Today」を追加できない。
2. ライトまたはダークのいずれかで、Widget・本文アプリの主要文字が背景と区別できない。
3. Widgetチェックが画面遷移を起こす、または本文タップが詳細を開かない。
4. Today起点の詳細が閉じる・戻るでTodayへ戻らない。
5. 自動テスト、通常版・本人用版のクリーンAndroid生成、署名ビルド、実機受入のいずれかが未合格である。

## 5. 反復工程

各修正では、仕様更新 → 設計レビュー → 実装 → 静的・統合・ネイティブ生成テスト → 修正 → 全回帰 → 署名ビルド → Android実機受入の順に進める。自動検証は実機上のWidget追加、文字のコントラスト、タップ判定を代替できないため、両者を別の合格条件として記録する。
