# 厳格モードの設計範囲

2026-08-20

## 目的

厳格モードは、ユーザーが自ら有効にした集中制限を、必須Todo・習慣が残っている間に**Focus Flow内で誤って解除しない**ための任意設定です。通常の集中制限に加え、遮断オーバーレイからのアプリ情報導線を非表示にし、設定画面の通常トグルから制限をオフにできないようにします。

## 実装する強化

| 項目 | 通常モード | 厳格モード |
|---|---|---|
| 制限アプリの前面化 | 継続遮断オーバーレイ | 同じ継続遮断オーバーレイ |
| Focus Flow内の制限オフ | いつでも変更可能 | 未完了の必須項目がある間は保護 |
| 遮断画面のアプリ情報導線 | 表示 | 非表示 |
| モード終了 | 不要 | 明示確認が必要 |

## 技術的な境界

通常の個人向けAndroidアプリは、端末のアクセシビリティ設定を無効化する操作、アプリの強制停止・削除、端末の再起動を禁止できません。これらを制御するロックタスクモードは、端末所有者または組織管理のDPCとして端末をセットアップした専用端末向けの仕組みです。[1]

Focus Flowは個人端末向けのアプリとして、端末全体をロックするDPC・キオスクモードを導入せず、ユーザーが明示的に選んだアプリにだけアクセシビリティオーバーレイを適用します。アクセシビリティサービスは、要求した前面化イベントを受け取り、アクティブウィンドウを確認できるため、再開・再起動時の再遮断に使います。[2]
