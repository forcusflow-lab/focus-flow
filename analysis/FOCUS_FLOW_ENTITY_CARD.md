# Focus Flow — 事業エンティティカード

| 項目 | 現時点の内容 |
| --- | --- |
| 名称 | Focus Flow |
| 法的主体 | **未確定**。正式公開前に、個人名または事業者名をプライバシーポリシー・ストア連絡先へ確定する。 |
| 上場状況 | 非上場・開発中の独立モバイルアプリ。 |
| 対象地域 | Google Playを通じた世界展開を目標とするが、初期検証はクローズドベータから開始する。 |
| 対象OS | Androidを先行。必須Todo・習慣の未完了時に選択アプリを制限する機能はAndroidネイティブ実装。 |
| 顧客像 | 日々のタスク・習慣の先延ばしを減らしたいAndroid利用者。特に、アプリ制限を行動完了と結びつけたい人。 |
| 価値提案 | 「必須Todo・必須習慣を終えるまで、選んだアプリを使いにくくする」という行動完了型の集中支援。ローカル保存・時間帯ルール・習慣・メモを統合する。 |
| 現行収益 | なし。Google Play BillingによるPlusサブスクリプションは設計段階であり、課金実装・商品登録・購入テストは未完了。 |
| 想定収益モデル | 無料の基本利用 + Plusサブスクリプション。価格仮説は月額USD 4.99、年額USD 29.99で、実測の転換率・継続率で検証する。 |
| 主要固定コスト | Google Playデベロッパー登録、法務・プライバシー対応、カスタマーサポート、分析・障害対応、将来の課金・バックエンド基盤。開発者自身の人件費は今回の初期損益分岐から分離して扱う。 |
| 主な不確実性 | 取得単価、ストア閲覧からのインストール率、無料から有料への転換率、月次解約率、AccessibilityServiceのGoogle Play審査、開発者の継続投下時間。 |
